# 宏观资产配置 Agent

这个项目同时支持：

1. 根据当前宏观环境生成股票、债券、黄金配置建议；
2. 将同一套配置逻辑放回 1995–2025 年进行历史回测；
3. 与 60/40 股债、股债金各 1/3、纯股票三种规则基准比较；
4. 在图形界面中查看累计财富、最大回撤和每月历史建议。
5. 检索不同投资人、科技公司CEO和AI专家对当今 AI 泡沫的分析，并返回观点日期和来源。
6. 用 Ray Dalio 公开的六项泡沫指标生成统一阶段判断、综合结论和下一阶段触发条件。
7. 根据职业收入、现金流、家庭负担、投资期限和风险承受能力生成个人适配配置，再在个人上限内叠加宏观信号。

## 启动图形界面

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 部署到 Streamlit Community Cloud

1. 将项目上传到 GitHub，确保 `.env` 和 `.streamlit/secrets.toml` 没有被提交；
2. 在 Streamlit Community Cloud 新建应用，入口文件选择 `app.py`；
3. 在应用 Secrets 中添加 `DEEPSEEK_API_KEY`，可选添加 `DEEPSEEK_MODEL = "deepseek-chat"`；
4. 保存并部署。宏观分析、历史回测和知识库可直接运行；Agent 对话通过 DeepSeek API 联网回答。

## 命令行使用 Agent

```bash
python agent.py
```

可以询问：

- “根据当前环境应该怎样配置？”
- “如果这个 Agent 从 1995 年开始运行，能跑赢 60/40 吗？”
- “按 25bp 交易成本回测，并和股债金等权比较。”
- “Howard Marks 和 Andrew Ng 对 AI 泡沫的判断有什么分歧？”
- “哪些人认为 AI 基础设施过热，但应用层仍然投资不足？”
- “我是自由职业者，结合我的收入支出和当前环境应该怎么配置？”

## AI 泡沫知识库

- 原始数据：`knowledge/ai_bubble_views.json`
- 检索模块：`knowledge_base.py`
- 统一诊断：`knowledge/ai_bubble_diagnosis.json` 与 `ai_bubble_diagnosis.py`
- 每条记录包含人物、角色、观点日期、立场、论据、风险、观察指标、来源链接和可信度。
- 新增人物时按现有 JSON 结构追加记录即可，无需重新训练模型。
- 当前诊断为“泡沫扩张后期／盈利验证拐点”，评分是研究框架复刻，不代表 Bridgewater 官方专有指标。

## 个人适配配置

- 模块：`personal_allocation.py`
- 图形界面已将“当前建议”和“个人适配配置”合并为“综合配置建议”；先展示环境信号，再填写职业、现金流、家庭责任、期限和风险信息，最终只输出一套综合权重。
- 个人战略配置占75%，当前宏观信号占25%；宏观信号不能突破个人股票上限。
- 应急资金、近期必用资金和高息债务在风险资产配置之前处理。
- Agent 不会再把宏观模型原始权重直接称为个人建议；缺少个人资料时会先补充询问。

## 回测约束

- 月末宏观信号在下个月执行，避免未来函数；
- 股票数据不含股息；
- 债券收益为 10 年期国债收益率构造的久期代理；
- 宏观数据是修订后终值，不是历史时点的 vintage；
- 所有比较对象都是规则基准，不代表现实机构的历史持仓。
